## Визуальное направление

Утверждён стиль `terminal editorial`: техническая эстетика без буквальной имитации IDE.

- Угольный фон, светлый основной текст, зелёный цвет для prompt/status и розовый акцент из фотографии.
- Моноширинный системный шрифт используется для заголовков, дат, команд и технологических меток.
- Длинные описания набираются системным sans-serif для нормальной читаемости.
- Терминальная команда появляется один раз в начале каждой секции. Номера строк, панели редактора и декоративные окна не используются.
- На широком экране слева находится компактная фиксированная панель с фотографией, именем, контактами и навигацией. Основное содержание остаётся одной читаемой колонкой.
- На мобильном экране боковая панель заменяется компактным header. Имя, роль и контакты не исчезают.
- Для печати фон становится белым, декоративные элементы и навигация скрываются, ссылки выводятся разборчиво.

## Мини-фреймворк и шаблоны

Исходники превращаются в небольшой генератор статического резюме:

- Содержание резюме хранится отдельно в структурированном JSON-файле. Для изменения роли, периода, описания, проекта, навыка или контакта не требуется редактировать HTML.
- Разметка хранится в HTML-шаблоне. Сборщик подставляет в него сгенерированные секции.
- Тема `terminal editorial` хранится в отдельном CSS-файле. Другую стилизацию можно подключить без изменения данных резюме.
- Локальные изображения и favicon копируются в итоговый каталог при сборке.
- Результат всегда создаётся в `dist/`; файлы в `dist/` не редактируются вручную.

Это намеренно маленький framework проекта, а не новая runtime-зависимость. Сборщик пишется на стандартной библиотеке Node.js, экранирует текст из JSON и завершается с ошибкой при отсутствии обязательных данных или файлов шаблона. Новые npm-пакеты не добавляются.

Bootstrap, jQuery, jQuery Easing и Font Awesome удаляются. Плавная прокрутка делается через CSS. Для scroll spy используется один небольшой скрипт на стандартном `IntersectionObserver`, без библиотек.

## Scroll spy

- Активный раздел подсвечивается одновременно в боковом и мобильном меню.
- Скрипт ставит соответствующим ссылкам `aria-current="location"` и снимает атрибут с остальных.
- Зелёный цвет показывает текущий раздел. Дополнительный маркер или подчёркивание сохраняет смысл без опоры только на цвет.
- При открытии страницы активен раздел из URL hash, а если hash нет, раздел «Обо мне».
- Слежение работает через `IntersectionObserver`, без постоянного обработчика `scroll`.

## GitHub Pages

Workflow в `.github/workflows/pages.yml` запускается для изменений основной ветки и вручную. Он:

1. Получает исходники репозитория.
2. Устанавливает поддерживаемую версию Node.js.
3. Запускает проверки и production-сборку.
4. Загружает содержимое `dist/` как GitHub Pages artifact.
5. Публикует artifact через официальный GitHub Pages action в окружение `github-pages`.

Workflow получает только минимальные права `contents: read`, `pages: write` и `id-token: write`. Секреты и SSH-ключи в репозиторий и workflow не добавляются.

## Доступность и адаптивность

- Семантические `header`, `nav`, `main`, `section`, `article`, корректная последовательность заголовков и один `h1`.
- Skip-link перед навигацией.
- Основной текст не меньше `1rem`, метаданные не меньше `0.8125rem`, межстрочный интервал основного текста не меньше `1.55`.
- Контраст текста соответствует WCAG AA. Розовый и зелёный не используются как единственный носитель смысла.
- Все ссылки имеют видимый `:focus-visible`; inline-ссылки подчёркнуты.
- Текущий пункт навигации имеет `aria-current="location"` и визуальный маркер.
- Навигация и контакты имеют удобные области нажатия на сенсорных устройствах.
- На ширине 320 px нет горизонтальной прокрутки и потери содержания.
- Анимации необязательны; `prefers-reduced-motion` отключает плавную прокрутку.

## Проверка результата

- Открытие страницы без ошибок браузерной консоли и без запросов к удалённым JS/CSS библиотекам.
- Чистая сборка из исходных JSON, HTML, CSS и изображений создаёт полный каталог `dist/`.
- Ошибка в обязательном поле данных или отсутствующий шаблон останавливают сборку с понятным сообщением.
- Проверка desktop и 320/390 px: имя, роль, контакты и весь опыт доступны.
- Проверка клавиатурой: skip-link и каждая ссылка получают видимый focus.
- Проверка печати: белый фон, чёрный текст, нет обрезанных блоков и пустой боковой колонки.
- Проверка HTML ссылок, `alt` фотографии, meta description и русского языка документа.
- Визуальная проверка нового портретного кропа и основных секций.
- Проверка scroll spy при переходе между разделами в desktop- и mobile-меню.
- Проверка синтаксиса GitHub Actions workflow и состава Pages artifact.
